GoPro NAS Sync

Welcome to GoPro NAS Sync

This app copies the photos and videos from your GoPro to your NAS. The Raspberry Pi wakes the camera over Bluetooth, downloads new files over the camera's Wi-Fi and writes them to the NAS through its network cable.

Three steps to get started

    Tip: if your Pi is a Pi 3 Model B or Zero 2 W, set the camera's Wi-Fi band to 2.4 GHz first. Why?

        NAS target

        Where the files go. Create a shared folder and a user with write access on your NAS first, then enter them here, click Test connection and Save and mount. The Pi reaches the NAS through its network cable. Step-by-step guide (with Synology example) 
        
    
        
    
        Type
        SMB / CIFS works with Synology, QNAP,
      Windows and almost every NAS. Choose NFS only if you already use NFS. Existing directory is for
      a folder you mount on the Pi yourself.
        
    
        Server
        The NAS's IP address or name, for example
      192.168.1.10 or diskstation.local. You find it in your router's device list or in
      Synology Assistant. It must be on your wired network, not on the camera's network (10.5.5.x).
        
    
        Share name / export path
        SMB: the name of the shared
      folder as shown on the NAS, for example video (no slashes). NFS: the full export path, for
      example /volume1/video on Synology.
        
    
        Protocol version
        Leave empty to let the Pi and the
      NAS agree. Only if the test fails with a protocol error, try 3.0 or 2.1 (SMB), or
      4.1 / 3 (NFS).
        
    
        Username and password
        A NAS user with
      Read/Write permission on the shared folder. Creating a dedicated user (for example gopro)
      is a good idea. The password is stored on the Pi and only readable by the system.
        
    
        Sub directory
        A folder inside the share where all
      GoPro files go, created automatically. Leave empty to write directly into the share.
        
    
        Folder layout
        How files are sorted below the sub
      directory. {camera}/{date} gives HERO11 Black 2106/2026-10-18/GX010034.MP4.
      {year}/{month} gives 2026/10/GX010034.MP4. {folder} is the camera's
      folder, for example 100GOPRO.
